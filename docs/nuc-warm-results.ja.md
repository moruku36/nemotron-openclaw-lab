# CPU 専用 NUC での Nemotron × OpenClaw：未ロード時と常駐時の実測

[English](nuc-warm-results.md) · 2026年11月24日（JST）

**OpenClaw の組み込みエージェントは、指定どおりの短文を3回とも返した。モデル常駐時はロード時間がほぼなくなったが、この実測ではエージェント応答は速くならなかった。**

| 新規セッション | 推論直前のモデル | 完全一致した応答 | エージェント CLI | Ollama 合計 | Ollama ロード | 入力評価（報告トークン数／時間） | ネイティブ最初の可視フレーム |
| --- | --- | --- | ---: | ---: | ---: | ---: | ---: |
| 1. 英語対照 | 未ロード | `PONG`（4 B） | 95.428 s | 77.690 s | 2.049 s | 2,055 / 75.369 s | 77.430 s |
| 2. 日本語 | 常駐 | `了解`（6 B） | 103.437 s | 84.184 s | 1.268 ms | 2,058 / 83.953 s | 84.004 s |
| 3. 英語対照、同一ユーザー入力 | 常駐 | `PONG`（4 B） | 106.937 s | 88.624 s | 0.946 ms | 2,053 / 88.228 s | 88.281 s |

実際の `openclaw agent --local` が各ターンにつき1件だけ、ループバックの観測プロキシを介して Ollama のネイティブ `POST /api/chat` を呼んだ。Ollama の可視本文と OpenClaw の最終ペイロードはトリムせずバイト単位で完全一致し、両方とも `stop`。全ターンでツール定義・ネイティブのツール呼び出しはともに0件。CLI 時間はコマンド開始から終了まで、最初の可視フレームはプロキシからネイティブに要求を送った時点から測った。

**構成。** Intel NUC（Core i5-1135G7、CPU のみ）、OpenClaw 2026.11.7、Ollama 0.40.17、Nemotron 3 Nano 4B Q4_K_M（`nemotron-3-nano:4b-q4_K_M`）。Linux/amd64 イメージの manifest / config とモデルは前回のコールド試験と同じ検証済みダイジェストで固定した。モデル manifest は `sha256:6cc467f054393a55e98a74098abde0c762ffb6d1d8cd64becf30458f38886197`。コンテキストは16,384、モデルのスレッド数2、出力上限32トークン、思考オフ、keep-alive 2分。Ollama は1インスタンスを保持し、OpenClaw は毎回新しいコンテナとセッションを使用した。各転送直前の `GET /api/ps` で、1回目は未ロード、2・3回目は CPU 常駐（VRAM 0 B）を確認した。入力は `Reply with exactly: PONG`、`次の二文字だけ返してください：了解`、英語の同一入力の順。日本語を同じ負荷と見なさず比較できるよう、英語の同文を1回だけ再測定した。

**資源と回収。** Ollama は2 CPU / 8 GiB、OpenClaw は1 CPU / 2 GiBの上限を維持し、両者でループバック専用のネットワーク名前空間を共有した。追加マウント・公開ポートなし。Ollama の cgroup CPU 使用時間は各エージェント実行を囲む区間で順に 155.598 / 168.616 / 177.459 CPU秒。Ollama 全試験のピーク RAM は 4,199.19 MiB（4.101 GiB）、各 OpenClaw のピークは 1,031.71 / 1,028.95 / 1,026.11 MiB。両者ともピークスワップは 0 B。いずれもコンテナ別で、ホスト全体の値ではない。試験用コンテナ、一時イメージ参照、非公開のモデルコピーを回収し、既存 Docker コンテナ・イメージの在庫が前後で一致することを確認した。

**読み取り。** 別試行の前回コールドでも、組み込み経路で `PONG` に完全一致した（CLI 94.732 s、Ollama 75.913 s）。今回も入力評価時間が大半を占め、同じ英語ユーザー入力の常駐時サンプルは全体では遅かった。新規セッションでは OpenClaw が付加する時刻などの内容が変わり得る。モデルの常駐はプロンプトキャッシュの再利用を証明せず、入力評価の報告トークン数はキャッシュヒット数や新規評価トークン数を表すとは限らない。単発値であり、速度差の原因やスループットは確定しない。日本語は指定の二文字1件のみ。旧 Gateway の不一致原因、本番適性、NemoClaw / OpenShell の Stage 3 は未検証。
